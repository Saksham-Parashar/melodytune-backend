# MelodyTune Backend 🎵

MelodyTune Backend is a REST API built with Node.js, Express.js, and MongoDB for a music streaming application. It provides user authentication, role-based access, music uploads, and album management.

## Features

- User registration and login
- Password hashing with bcrypt
- JWT-based authentication using cookies
- Role-based access for users and artists
- Music upload and storage using ImageKit
- Create and retrieve music albums
- MongoDB database integration using Mongoose

## Tech Stack

- **Node.js** — JavaScript runtime
- **Express.js** — REST API framework
- **MongoDB Atlas** — Cloud database
- **Mongoose** — MongoDB object modeling
- **JSON Web Token (JWT)** — Authentication
- **bcryptjs** — Password hashing
- **Multer** — File upload handling
- **ImageKit** — Music file storage
- **dotenv** — Environment variable management
- **cookie-parser** — Cookie parsing
